## ✨ Features of the Portfolio Website

- **Interactive Neural Background Canvas**: Real-time particle-mesh simulation simulating neural synapses that dynamically reacts to cursor movements.
- **Animated Metrics**: Smooth animated stat counters triggered on viewport entry.
- **Dynamic Publication Filtering & Live Search**: Instant keyword search with term highlighting and category filters (Medical AI, IEEE, Applied Systems).
- **Academic Citation Generator**: One-click citation modal providing formatted BibTeX, APA, and MLA citations.
- **Expandable Patent Specifications**: Interactive technical details for registered patents.
- **Modals for Document Verification**: Interactive viewers for the official ACM Membership Certificate and University Event posters.
- **Dark / Light Mode**: High-contrast theme toggle with system preference detection and local storage persistence.
- **Responsive & Accessible**: Optimized for mobile, tablet, and desktop viewports, with a dedicated print stylesheet for CV printing.

## 🚀 Local Development

To run this website locally:

```bash
# Clone the repository
git clone https://github.com/AnantHejib/dr-shubhangi-patil-portfolio.git

# Navigate to the folder
cd dr-shubhangi-patil-portfolio

# Start a simple local server (Python 3)
python -m http.server 8000
```

Open `http://localhost:8000` in your web browser.
